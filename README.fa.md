# ابزارهای امنیتی پایتون

مجموعه‌ای منتخب از ابزارهای امنیتی پایتون که با هدف یادگیری، آزمایش، خودکارسازی و ساخت نمونه‌کار توسعه داده شده‌اند.

این مخزن شامل ابزارهای کاربردی مبتنی بر پایتون است که حوزه‌هایی مانند شبکه، تحلیل سیستم، پردازش لاگ و خودکارسازی را پوشش می‌دهند. هر پروژه در پوشهٔ اختصاصی خود سازمان‌دهی شده و شامل مستندات، مثال‌های استفاده و منابع آموزشی است.

---

## اهداف

<p dir='rtl'>
• ساخت ابزارهای کاربردی مرتبط با امنیت با استفاده از پایتون <br>
• یادگیری مفاهیم شبکه و برنامه‌نویسی سیستم <br>
• حفظ کیفیت کد و مستندسازی مناسب <br>
• ایجاد ابزارهای قابل استفادهٔ مجدد برای سناریوهای واقعی <br>
• ارائهٔ مستندات آموزشی دوزبانه (انگلیسی و فارسی)
</p>
