# اسکنر پورت TCP

یک اسکنر سبک پورت TCP نوشته‌شده با پایتون که با هدف یادگیری، آزمایش و خودکارسازی عملی در حوزه امنیت توسعه یافته است.

این پروژه بر معماری تمیز پایتون، قابلیت تست‌پذیری، نتایج ساختاریافته اسکن، تشخیص سرویس، دریافت بنر، ثبت لاگ و خروجی JSON/CSV تمرکز دارد.

> **هشدار:** از این ابزار فقط روی سیستم‌هایی استفاده کنید که مالک آن هستید یا مجوز صریح برای تست آن‌ها دارید.

## نصب

مخزن را Clone کرده و وارد پوشه پروژه شوید:

```bash
git clone https://github.com/QUANTORIS01/python-security-tools.git

cd python-security-tools/port_scanner
```

محیط مجازی ایجاد کنید:

```bash
python -m venv .venv
```

در PowerShell ویندوز فعال کنید:

```powershell

```

وابستگی‌های توسعه را نصب کنید:

```bash
pip install -r requirements.txt
```

## تشخیص سرویس

برای هر پورت باز TCP، اسکنر تلاش می‌کند با استفاده از کتابخانه استاندارد پایتون نام سرویس ثبت‌شده آن پورت را تشخیص دهد.

مثال:

```text
53   → domain
135  → epmap
445  → microsoft-ds
```

این نام‌ها از پایگاه داده سرویس‌های محلی سیستم به دست می‌آیند و لزوماً نشان‌دهنده نرم‌افزار واقعی در حال اجرا روی میزبان مقصد نیستند.

---

## دریافت بنر (Banner Grabbing)

اسکنر تلاش می‌کند بنر عمومی سرویس‌های TCP باز را دریافت کند.

مثال:

```text
22 OPEN ssh SSH-2.0-TestServer
```

در این نسخه دریافت بنر به صورت عمومی انجام می‌شود. برخی پروتکل‌ها بلافاصله پس از اتصال بنر ارسال می‌کنند و برخی دیگر نیازمند درخواست اختصاصی پروتکل هستند.

بنابراین خالی بودن بنر لزوماً به معنای ناشناخته بودن یا در دسترس نبودن سرویس نیست.

## نتایج اسکن

پورت‌های باز با استفاده از Dataclass زیر نمایش داده می‌شوند:

```python
ScanResult(
    port=22,
    service="ssh",
    banner="SSH-2.0-TestServer",
)
```

این مدل داده‌ها را ساختاریافته نگه می‌دارد و نمایش و خروجی‌گیری را ساده‌تر می‌کند.
