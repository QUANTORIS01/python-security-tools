# جلسه ۰۲ - پایتون چیست؟

## مقدمه

در جلسه قبل یاد گرفتیم که برنامه‌نویسی یعنی نوشتن دستوراتی که کامپیوتر بتواند آن‌ها را اجرا کند.

اما یک سؤال مهم وجود دارد:

اگر بخواهیم به کامپیوتر دستور بدهیم، این دستورها را با چه زبانی باید بنویسیم؟

اینجاست که زبان‌های برنامه‌نویسی وارد ماجرا می‌شوند.

---

## زبان برنامه‌نویسی چیست؟

همان‌طور که انسان‌ها با زبان‌های مختلف صحبت می‌کنند:

<p dir='rtl'>
• فارسی <br>
• انگلیسی <br>
• عربی <br>
• ترکی
</p>

کامپیوترها نیز برای فهمیدن دستورات به یک زبان نیاز دارند.

به این زبان‌ها، **زبان‌های برنامه‌نویسی** گفته می‌شود.

---

## اولین برنامه پایتون

فایل زیر را ایجاد کنید:

```python
hello.py
```

محتوای فایل:

```python
print("سلام دنیا")
```

اجرای برنامه:

```bash
python hello.py
```

خروجی:

```text
سلام دنیا
```

## چرا برای پروژه Port Scanner از پایتون استفاده کردیم؟

چند دلیل مهم وجود دارد:

### ۱- سادگی

کدهای پایتون بسیار خوانا هستند.

مثال:

```python
socket.connect(("127.0.0.1", 80))
```

حتی بدون دانش زیاد نیز می‌توان حدس زد که این کد در حال اتصال به یک IP و یک Port است.

---

### ۲- کتابخانه‌های آماده

پایتون کتابخانه‌های قدرتمندی دارد.

برای مثال:

```python
socket
```

برای ارتباطات شبکه.

```python
ipaddress
```

برای اعتبارسنجی IP.

```python
json
```

برای ذخیره‌سازی خروجی.

---

### ۳- سرعت توسعه

با پایتون می‌توان ابزارهای کاربردی را در زمان کوتاهی توسعه داد.

پروژه Port Scanner ما نیز با همین زبان پیاده‌سازی شده است.
