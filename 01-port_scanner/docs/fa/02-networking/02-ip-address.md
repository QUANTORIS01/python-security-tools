# جلسه ۲: آدرس IP چیست؟

# مقدمه

در جلسه قبل فهمیدیم که:

<p dir='rtl'>
• شبکه چیست <br>
• Client چیست <br>
• Server چیست
</p>

اما هنوز یک سؤال مهم باقی مانده است:

❓ وقتی میلیاردها دستگاه به شبکه متصل هستند، چطور می‌توانیم یک دستگاه خاص را پیدا کنیم؟

پاسخ:

```text
IP Address
```

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
IP چیست؟
</p>

<p dir='rtl'>
IP مخفف عبارت زیر است:
</p>

```text
Internet Protocol Address
```

به زبان ساده:

<p dir='rtl'>
IP آدرس هر دستگاه در شبکه است.
</p>

درست مانند آدرس خانه.

---

# مثال از دنیای واقعی

فرض کن می‌خواهی نامه‌ای برای دوستت ارسال کنی.

اگر فقط روی نامه بنویسی:

```text
علی
```

پست نمی‌فهمد نامه را کجا ببرد.

اما اگر بنویسی:

```text
تهران
خیابان ...
کوچه ...
پلاک ...
```

نامه به مقصد می‌رسد.

---

کامپیوترها نیز دقیقاً همین مشکل را دارند.

برای همین هر دستگاه یک آدرس دارد.

به این آدرس می‌گوییم:

```text
IP Address
```

---

# نمونه IP

```text
192.168.1.10
```

یا:

```text
8.8.8.8
```

یا:

```text
1.1.1.1
```

---

# چرا Port Scanner به IP نیاز دارد؟

فرض کن بنویسیم:

```python
scan_target()
```

مشخص نیست کدام دستگاه را اسکن کنیم.

اما اگر بنویسیم:

```python
scan_target("192.168.1.10")
```

اکنون می‌دانیم هدف کدام دستگاه است.

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
IPv4 چیست؟
</p>

رایج‌ترین نوع IP:

```text
IPv4
```

نمونه:

```text
192.168.1.10
```

---

<p dir='rtl'>
IPv4 از ۴ بخش تشکیل شده است.
</p>

مثال:

```text
192.168.1.10
```

بخش اول:

```text
192
```

بخش دوم:

```text
168
```

بخش سوم:

```text
1
```

بخش چهارم:

```text
10
```

---

هر بخش عددی بین:

```text
0 تا 255
```

است.

---

# مثال‌های معتبر

```text
192.168.1.1
```

```text
10.0.0.1
```

```text
172.16.5.20
```

---

# مثال‌های نامعتبر

```text
300.1.1.1
```

زیرا:

```text
300 > 255
```

---

```text
192.168.1
```

زیرا چهار بخش ندارد.

---

```text
abc.def.ghi.jkl
```

زیرا عدد نیست.

---

# دلیل ساخت validator.py

به همین دلیل در پروژه Port Scanner فایل زیر را ساختیم:

```text
validator.py
```

---

وظیفه آن:

بررسی صحت IP

---

مثال:

```python
validate_ip("192.168.1.10")
```

خروجی:

```python
True
```

---

مثال:

```python
validate_ip("500.1.1.1")
```

خروجی:

```python
False
```

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
IPv4 محدودیت دارد
</p>

<p dir='rtl'>
IPv4 تقریباً:
</p>

```text
4.3 Billion
```

آدرس تولید می‌کند.

---

در گذشته این عدد خیلی زیاد بود.

اما امروزه:

<p dir='rtl'>
• موبایل <br>
• لپ‌تاپ <br>
• سرور <br>
• تلویزیون <br>
• دوربین <br>
• ساعت هوشمند
</p>

همگی IP نیاز دارند.

---

در نتیجه IPv4 کم کم به مشکل کمبود آدرس رسید.

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
IPv6 چیست؟
</p>

برای حل این مشکل:

```text
IPv6
```

ساخته شد.

---

نمونه IPv6:

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

---

تعداد آدرس‌های IPv6 آن‌قدر زیاد است که عملاً تمام نمی‌شود.

---

# آیا Port Scanner ما IPv6 را پشتیبانی می‌کند؟

فعلاً خیر.

---

پروژه فعلی فقط:

```text
IPv4
```

را پشتیبانی می‌کند.

---

بعداً اگر بخواهیم پروژه را به سطح حرفه‌ای‌تر نزدیک کنیم می‌توانیم:

```text
IPv6 Support
```

را اضافه کنیم.

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
Public IP چیست؟
</p>

وقتی به اینترنت متصل می‌شوی:

شرکت اینترنت یک IP به تو می‌دهد.

مثال:

```text
85.x.x.x
```

این IP در کل اینترنت قابل مشاهده است.

---

به این نوع می‌گوییم:

```text
Public IP
```

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
Private IP چیست؟
</p>

داخل شبکه خانه معمولاً آدرس‌هایی مثل:

```text
192.168.1.10
```

داریم.

یا:

```text
192.168.1.20
```

---

این IPها فقط داخل شبکه خانه معتبر هستند.

---

به این نوع می‌گوییم:

```text
Private IP
```

---

# معروف‌ترین محدوده‌های Private IP

---

## کلاس اول

```text
10.0.0.0
تا
10.255.255.255
```

---

## کلاس دوم

```text
172.16.0.0
تا
172.31.255.255
```

---

## کلاس سوم

```text
192.168.0.0
تا
192.168.255.255
```

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
IP کامپیوتر خودمان را چگونه ببینیم؟
</p>

در ویندوز:

```powershell
ipconfig
```

---

در لینوکس:

```bash
ip addr
```

یا:

```bash
ifconfig
```

---

# مثال واقعی

خروجی ممکن است چیزی شبیه این باشد:

```text
IPv4 Address: 192.168.1.100
```

---

این یعنی:

کامپیوتر تو در شبکه داخلی این آدرس را دارد.

---

# ارتباط IP با Port Scanner

وقتی این دستور را اجرا می‌کنیم:

```bash
python -m src.cli 127.0.0.1 1 1000
```

بخش:

```text
127.0.0.1
```

در حقیقت IP هدف است.

---

اسکنر تلاش می‌کند به این IP متصل شود.

و وضعیت پورت‌ها را بررسی کند.

---

<p dir='rtl' style='font-size:32px; font-wight:bold'>
Loopback چیست؟
</p>

یکی از معروف‌ترین IPها:

```text
127.0.0.1
```

است.

---

به آن می‌گویند:

```text
Loopback
```

یا:

```text
localhost
```

---

این IP به خود کامپیوتر اشاره می‌کند.

---

مثال:

```bash
ping 127.0.0.1
```

---

یعنی:

«آیا خودم در دسترس هستم؟»

---

به همین دلیل اکثر تست‌های ما روی:

```text
127.0.0.1
```

انجام شدند.
