# What Is Cybersecurity?

Cybersecurity is the field of protecting:

- Computers
- Servers
- Networks
- Software
- Data

against threats and attacks.

---

# A Simple Example

Suppose you have a house.

---

To protect it, you use:

```text
Locks
Doors
Cameras
Guards
Alarm systems
```

---

The same thing happens in the digital world.

---

Instead of a house, we have:

```text
Computers
Servers
Websites
Networks
```

---

And instead of locks, we have:

```text
Firewall
Antivirus
Encryption
Authentication
```

---

# Why Is Cybersecurity Important?

Today, almost everything has become digital.

---

Example:

```text
Banking
Healthcare
Universities
Companies
Governments
Stores
```

---

If security did not exist:

---

It is possible that:

```text
Information is stolen
```

---

Or:

```text
Services go down
```

---

Or:

```text
Data is destroyed
```

---

# The Main Goal of Cybersecurity

Security is usually built on three important principles.

---

These three principles are called:

```text
CIA Triad
```

---

# Confidentiality

Confidentiality

---

Meaning:

```text
Only authorized people
```

should have access to information.

---

Example:

```text
Bank account password
```

---

should not be visible to everyone.

---

# Integrity

Integrity

---

Meaning:

```text
Information must not be altered
```

---

Example:

---

If the account balance is:

```text
1000$
```

it must not be changed by anyone to:

```text
100000$
```

---

# Availability

Availability

---

Meaning:

```text
The service must be accessible
```

---

Example:

---

The bank's website must open when the user needs it.

---

If the server goes down:

---

Availability has been lost.

---

# Cybersecurity Is Not Just for Hackers

Many people think:

```text
Cybersecurity = Hacking
```

---

But this assumption is wrong.

---

A large part of security involves:

```text
Defense
Management
Training
Analysis
Prevention
```

---

# Network Security

Network security

Networks

```

---

# Application Security

Application security

---

Protecting:

# Cloud Security

Cloud security

AWS

```

---

# Endpoint Security

Endpoint security

---

Information security

```text
Data
```

---

---

# What Is a Threat?

In security, we have a term:

```text
Threat
```

---

A Threat means:

```text
Anything that can cause harm
```

---

Example:

```text
Hacker
Malware
Virus
Ransomware
Insider Threat
```

---

# What Is a Vulnerability?

The term:

```text
Vulnerability
```

---

means:

```text
A security weakness
```

---

Example:

---

Suppose the password is:

```text
123456
```

---

This is a:

```text
Vulnerability
```

---

# What Is an Attack?

The term:

```text
Attack
```

---

occurs when an attacker exploits a weakness.

---

Example:

```text
Weak Password
```

↓

```text
Password Guessing
```

↓

```text
Unauthorized Access
```

---

# Does Perfect Security Exist?

No.

---

One of the most important concepts in security:

```text
Perfect Security Does Not Exist
```

---

No system is 100% secure.

---

The goal of security:

```text
Reducing risk
```

---

# What Is Risk?

The term:

```text
Risk
```

---

means:

```text
The probability of damage occurring
```

---

A simple formula:

```text
Risk = Threat × Vulnerability
```

---

The greater the weakness:

---

The greater the risk.

---
