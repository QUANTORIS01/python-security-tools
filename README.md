# Python Security Tools

A curated collection of Python security tools developed for learning, experimentation, automation, and portfolio building.

This repository contains practical Python-based security utilities ranging from networking and system analysis to log processing and automation. Each project is organized in its own directory and includes documentation, usage examples, and educational resources.

---

## Goals

* Build practical security-related Python tools
* Learn networking and system programming concepts
* Maintain clean and well-documented code
* Create reusable utilities for real-world tasks
* Provide bilingual educational documentation (English & Persian)
