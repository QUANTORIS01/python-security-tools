# Lesson 01: Introduction to Cybersecurity

## Introduction

Before we can build security tools, we need to know:

```text
What exactly is cybersecurity?
```

Many people equate cybersecurity simply with:

```text
Hacking
```

But in reality, cybersecurity is much broader than that.

---

# What Is Cybersecurity?

Cybersecurity refers to a set of processes, technologies, and methods used to protect:

- Systems
- Networks
- Applications
- Data

against unauthorized access, destruction, or misuse.

---

The main goal is:

```text
Protecting digital assets
```

---

# What Is an Asset?

In cybersecurity, anything that is worth protecting is called:

```text
Asset
```

---

Example:

- A laptop
- A server
- A website
- A database
- A password
- A user account
- Customer information

---

# Why Is Cybersecurity Important?

Today, almost everything is connected to the Internet:

- Banks
- Hospitals
- Governments
- Companies
- Regular users

---

Any security weakness can lead to:

- Information theft
- Data loss
- Financial damage
- Damage to an organization's reputation

---

# The Three Main Pillars of Security

Almost all of cybersecurity is built on three principles:

```text
CIA Triad
```

---

These three letters stand for:

```text
Confidentiality
Integrity
Availability
```

---

In the next lesson, we will examine this model in full.

---

# The Attacker

An attacker is an individual or group that tries to:

```text
Gain unauthorized access
to digital assets.
```

---

Attackers can be:

- Cybercriminals
- State-sponsored hackers
- Disgruntled employees
- Competitors

---

# The Defender

A defender is someone who protects systems.

---

Examples:

- Security Analyst
- SOC Analyst
- Incident Responder
- Security Engineer
- Blue Team

---

A large part of the tools we build are:

```text
Defensive Tools
```

---

# What Is a Hacker?

A hacker is not necessarily a criminal.

---

A hacker is someone who:

```text
Has a deep understanding of systems.
```

---

Hackers are usually divided into three groups:

### White Hat

Legal and ethical hackers

---

### Black Hat

Illegal attackers

---

### Gray Hat

Fall between these two groups.

---

# Security Is Not Just Tools

Many people think:

```text
Installing antivirus = security
```

---

But security is a combination of:

- People
- Processes
- Technology

---

# The Role of the Tools We Build

Tools such as:

- Port Scanner
- DNS Lookup
- Network Monitor
- Log Analyzer

are used for information gathering and environment analysis.

---

These tools are usually used in the stages of:

```text
Discovery
Monitoring
Investigation
Assessment
```

---
