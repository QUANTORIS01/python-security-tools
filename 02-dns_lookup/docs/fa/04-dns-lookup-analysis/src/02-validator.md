### ۱. هدف درس

در این درس یاد می‌گیریم:

<div align='right' dir='rtl'>

<span dir='rtl'>• چرا اعتبارسنجی ورودی‌ها در ابزارهای شبکه اهمیت دارد.</span> <br>
<span dir='rtl'>• چگونه با Regular Expression یا عبارت منظم، قالب یک دامنه را بررسی کنیم.</span> <br>
<span dir='rtl'>• چگونه مقدار `timeout` را اعتبارسنجی کنیم.</span> <br>
<span dir='rtl'>• چگونه نوع رکورد DNS را با مجموعه‌ای از مقادیر مجاز مقایسه کنیم.</span> <br>
<span dir='rtl'>• چرا معتبر بودن یک ورودی از نظر قالب، لزوماً به معنای معتبر بودن آن در دنیای واقعی نیست.</span>

</div>

### ۲. ساختار فایل

فایل `src/validator.py` شامل یک مجموعه از انواع رکوردهای پشتیبانی‌شده و سه تابع اعتبارسنجی است:

```python
import re

SUPPORTED_RECORD_TYPES = {
    'A',
    'AAAA',
    'MX',
    'NS',
    'TXT',
    'CNAME',
}
```

ماژول `re` ابزارهایی برای کار با عبارت‌های منظم فراهم می‌کند. در این فایل، از آن برای بررسی قالب نام دامنه استفاده شده است.

متغیر `SUPPORTED_RECORD_TYPES` از نوع `set` است و شش نوع رکورد DNS را نگه می‌دارد. مجموعه برای نگهداری مقادیر یکتا مناسب است و بررسی عضویت در آن نیز ساده است.

نکته: وجود یک نوع رکورد در این مجموعه به ما می‌گوید که اعتبارسنجی آن در این فایل پشتیبانی می‌شود؛ به‌تنهایی ثابت نمی‌کند که تمام انواع رکوردها در همه بخش‌های برنامه به‌درستی resolve یا پردازش می‌شوند.

### ۳. اعتبارسنجی نام دامنه

تابع اول:

```python
def validate_domain(domain: str) -> bool:
    """
    Validate a domain name.
    """
    pattern = (
        r'^(?!-)'
        r'(?:[A-Za-z0-9-]{1,63}\.)+'
        r'[A-Za-z]{2,63}$'
    )
    return bool(re.fullmatch(pattern, domain))
```

#### آشنایی با امضای تابع

```python
def validate_domain(domain: str) -> bool:
```

<div align='right' dir='rtl'>

<span dir='rtl'>• `domain: str` یک type hint است که نشان می‌دهد ورودی مورد انتظار رشته است.</span> <br>
<span dir='rtl'>• <span dir='ltr'>`-> bool`</span> نشان می‌دهد تابع برای اعلام نتیجه، مقدار بولی در نظر گرفته است.</span> <br>
<span dir='rtl'>• این type hintها به‌تنهایی نوع ورودی را در زمان اجرا کنترل نمی‌کنند.</span>

</div>

#### عبارت منظم چگونه کار می‌کند؟

الگوی تعریف‌شده از چند بخش تشکیل شده است:

<div align='center' dir='rtl'>

| بخش الگو | مفهوم |
|---|---|
| <span dir='ltr'>`^`</span> | ابتدای رشته |
| <span dir='ltr'>`(?!-)`</span> | در موقعیت ابتدای رشته، خط تیره نباید قرار داشته باشد |
| <span dir='ltr'>`[A-Za-z0-9-]{1,63}`</span> | یک تا ۶۳ نویسه از حروف انگلیسی، ارقام یا خط تیره |
| <span dir='ltr'>`\.`</span> | یک نقطه واقعی |
| <span dir='ltr'>`(?: ... )+`</span> | گروهی بدون ثبت جداگانه که یک یا چند بار تکرار می‌شود |
| <span dir='ltr'>`[A-Za-z]{2,63}`</span> | در بخش پایانی، دو تا ۶۳ حرف انگلیسی |
| <span dir='ltr'>`$`</span> | انتهای رشته |

</div>

تابع <span dir='ltr'>`re.fullmatch()`</span> بررسی می‌کند که کل رشته با الگو تطبیق داشته باشد. سپس <span dir='ltr'>`bool()`</span> نتیجه تطبیق را به `True` یا `False` تبدیل می‌کند.

برای مثال:

```python
print(validate_domain("example.com"))
print(validate_domain("api.example.com"))
print(validate_domain("-example.com"))
print(validate_domain("example"))
```

خروجی مورد انتظار:

```text
True
True
False
False
```

دو نمونه نخست از نظر الگوی فعلی پذیرفته می‌شوند. نمونه سوم با خط تیره شروع می‌شود و نمونه چهارم فاقد نقطه و بخش پایانی جداگانه است.

#### محدودیت مهم این اعتبارسنجی

این تابع یک بررسی مبتنی بر الگو انجام می‌دهد؛ پیاده‌سازی کامل استاندارد نام دامنه نیست.

برای مثال، الگوی فعلی می‌تواند برخی نام‌های نامعتبر را بپذیرد:

```python
print(validate_domain("exa_mple.com"))
print(validate_domain("example-.com"))
```

در این دو مورد، نتیجه تابع `True` است؛ زیرا الگو خط تیره در انتهای برچسب را منع نمی‌کند و در بخش‌های میانی نیز محدودیت کامل قواعد نام دامنه را اعمال نمی‌کند.

همچنین، چون بخش پایانی فقط حروف انگلیسی را می‌پذیرد، برخی نام‌های دامنه بین‌المللی که به شکل Unicode نوشته شده‌اند، مستقیماً پذیرفته نمی‌شوند.

**نتیجه:** این تابع بررسی قالبی با محدودیت‌های مشخص است؛ نباید آن را تضمین‌کننده وجود دامنه، معتبر بودن DNS آن یا دسترس‌پذیری سرور مقصد دانست.

### ۴. اعتبارسنجی زمان انتظار (Timeout)

تابع دوم:

```python
def validate_timeout(timeout: float) -> bool:
    """
    Validate DNS query timeout.
    """
    return timeout > 0
```

این تابع بررسی می‌کند که مقدار `timeout` از صفر بزرگ‌تر باشد.

```python
print(validate_timeout(3.0))
print(validate_timeout(0))
print(validate_timeout(-1))
```

خروجی:

```text
True
False
False
```

زمان انتظار مشخص می‌کند که یک عملیات تا چه مدت اجازه دارد برای پاسخ منتظر بماند. مقدار صفر یا منفی معمولاً برای چنین تنظیمی مناسب نیست؛ این تابع نیز دقیقاً همین شرط را بررسی می‌کند.

اما این تابع محدودیت‌های دیگری را بررسی نمی‌کند. برای نمونه، اگر ورودی `float('inf')` باشد، مقایسه `timeout > 0` نتیجه `True` می‌دهد. همچنین، `NaN` نتیجه مقایسه مثبت را نمی‌دهد و بنابراین `False` برمی‌گرداند.

نکته مهم: type hint از نوع `float` تضمین نمی‌کند که ورودی در زمان اجرا واقعاً عدد اعشاری باشد. در این تابع، نوع ورودی به‌صورت صریح بررسی نشده است.

اگر قرار باشد اعتبارسنجی سخت‌گیرانه‌تری پیاده‌سازی شود، باید مشخص شود که آیا مقادیر بی‌نهایت، `NaN`، رشته‌ها و سایر انواع ورودی مجاز هستند یا نه.

### ۵. اعتبارسنجی نوع رکورد DNS

تابع سوم:

```python
def validate_record_type(record_type: str) -> bool:
    """
    Validate DNS record type.
    """
    return record_type.upper() in SUPPORTED_RECORD_TYPES
```

این تابع ابتدا با <span dir='ltr'>`upper()`</span> حروف ورودی را به حروف بزرگ تبدیل می‌کند و سپس عضویت مقدار را در مجموعه `SUPPORTED_RECORD_TYPES` بررسی می‌کند.

```python
print(validate_record_type("A"))
print(validate_record_type("aaaa"))
print(validate_record_type("MX"))
print(validate_record_type("SOA"))
```

خروجی:

```text
True
True
True
False
```

به دلیل استفاده از <span dir='ltr'>`upper()`</span>، ورودی‌هایی مانند `"aaaa"` نیز پذیرفته می‌شوند؛ البته تنها وقتی مقدار تبدیل‌شده در مجموعه مجاز وجود داشته باشد.

این روش از تکرار مقایسه‌های جداگانه جلوگیری می‌کند و مجموعه مقادیر قابل قبول را در یک محل نگه می‌دارد.

با این حال، تابع فقط عضویت در مجموعه را بررسی می‌کند. برای نمونه، نوع ورودی را پیش از فراخوانی <span dir='ltr'>`upper()`</span> کنترل نمی‌کند؛ بنابراین ارسال مقداری مانند `None` باعث خطا می‌شود.

### ۶. ارتباط سه تابع با امنیت نرم‌افزار

اعتبارسنجی ورودی‌ها یکی از بخش‌های مهم توسعه امن است؛ زیرا ورودی نامناسب ممکن است باعث خطا، رفتار غیرمنتظره یا مصرف نامناسب منابع شود.

در این فایل سه کنترل مجزا داریم:

<div align='right' dir='rtl'>

<span dir='rtl'>• **نام دامنه:** بررسی قالب با عبارت منظم</span> <br>
<span dir='rtl'>• **زمان انتظار:** بررسی مثبت بودن مقدار</span> <br>
<span dir='rtl'>• **نوع رکورد:** بررسی عضویت در مجموعه مقادیر مجاز</span>

</div>

این کنترل‌ها مفید هستند، اما جایگزین مدیریت خطا، اعتبارسنجی در لایه‌های دیگر یا بررسی نتیجه واقعی عملیات DNS نمی‌شوند.

برای مثال، معتبر بودن قالب `example.com` تضمین نمی‌کند که دامنه وجود دارد. به همین ترتیب، پذیرفته شدن نوع رکورد `A` تضمین نمی‌کند که دامنه موردنظر رکورد `A` داشته باشد.

### ۷. تمرین‌های آموزشی

**تمرین اول — بررسی دامنه**

با استفاده از <span dir='ltr'>`validate_domain()`</span>، نتیجه ورودی‌های زیر را پیش‌بینی کنید و سپس با اجرای کد بررسی کنید:

```python
domains = [
    "example.com",
    "sub.example.org",
    "-example.com",
    "example-.com",
    "localhost",
    "example.c",
]

for domain in domains:
    print(domain, validate_domain(domain))
```

توضیح دهید چرا نتیجه هر مورد با توجه به عبارت منظم فعلی چنین است.

**تمرین دوم — بررسی Timeout**

```python
timeouts = [1, 0.5, 0, -2]

for timeout in timeouts:
    print(timeout, validate_timeout(timeout))
```

چه شرطی باعث می‌شود بعضی مقادیر پذیرفته و بعضی رد شوند؟

**تمرین سوم — نوع رکورد**

```python
record_types = ["A", "aaaa", "TXT", "SOA", "cname"]

for record_type in record_types:
    print(record_type, validate_record_type(record_type))
```

توضیح دهید نقش <span dir='ltr'>`upper()`</span> چیست و چرا `SOA` با وجود شناخته‌شده بودن به‌عنوان یک نوع رکورد DNS، در این پیاده‌سازی پذیرفته نمی‌شود.

**تمرین چهارم — طراحی اعتبارسنجی بهتر**

بدون تغییر دادن کد اصلی پروژه، پیشنهاد دهید چگونه می‌توان تابع <span dir='ltr'>`validate_timeout()`</span> را طوری توسعه داد که مقادیر غیرمتناهی نیز پذیرفته نشوند. برای این کار، درباره تابع <span dir='ltr'>`math.isfinite()`</span> در مستندات رسمی پایتون مطالعه کنید.
