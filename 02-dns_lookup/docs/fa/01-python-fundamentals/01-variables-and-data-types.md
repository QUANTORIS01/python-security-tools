# درس ۱: متغیرها و انواع داده در پایتون

## مقدمه

هر برنامه‌ای که می‌نویسیم باید بتواند اطلاعات را ذخیره و پردازش کند.

در پروژه DNS Lookup نیز با اطلاعات مختلفی سروکار داریم، مانند:

• نام دامنه <br>
• نوع رکورد DNS <br>
• مقادیر بازگشتی <br>
• وضعیت‌های مختلف برنامه

برای نگهداری این اطلاعات از **متغیرها (Variables)** استفاده می‌کنیم.

---

# متغیر چیست؟

متغیر یک نام است که به یک مقدار در حافظه اشاره می‌کند.

مثال:

```python
domain = "google.com"
```

در این مثال:

<div align='right'>

<span dir='rtl'> • `domain` نام متغیر است. </span> <br>
<span dir='rtl'> • `"google.com"` مقدار ذخیره‌شده در آن است. </span>

</div>

---

# ساخت متغیر

در پایتون نیازی به تعریف نوع متغیر قبل از استفاده نیست.

مثال:

```python
name = "Ali"
age = 25
```

پایتون به صورت خودکار نوع داده را تشخیص می‌دهد.

---

# انواع داده‌های اصلی

پایتون انواع داده مختلفی دارد اما در این پروژه بیشتر با چند نوع اصلی سروکار داریم.

---

## رشته (String)

برای نگهداری متن استفاده می‌شود.

مثال:

```python
domain = "google.com"
record_type = "A"
```

در پروژه DNS Lookup تقریباً تمام ورودی‌های کاربر ابتدا به صورت رشته دریافت می‌شوند.

مثال:

```python
python -m src.cli google.com A
```

مقادیر:

```python
domain = "google.com"
record_type = "A"
```

---

## عدد صحیح (Integer)

برای نگهداری اعداد صحیح استفاده می‌شود.

مثال:

```python
count = 5
```

نمونه‌های رایج:

```python
records_found = 10
```

---

## عدد اعشاری (Float)

برای اعداد دارای قسمت اعشاری استفاده می‌شود.

مثال:

```python
timeout = 2.5
```

---

## مقدار بولی (Boolean)

فقط دو مقدار دارد:

```python
True
False
```

مثال:

```python
is_valid = True
```

در پروژه ما تابع‌های اعتبارسنجی از این نوع استفاده می‌کنند.

مثال:

```python
validate_domain("google.com")
```

خروجی:

```python
True
```

---

# بررسی نوع داده

برای مشاهده نوع یک متغیر از تابع <span dir='ltr'>`type()`</span> استفاده می‌کنیم.

مثال:

```python
domain = "google.com"

print(type(domain))
```

خروجی:

```python
<class 'str'>
```

مثال دیگر:

```python
number = 10

print(type(number))
```

خروجی:

```python
<class 'int'>
```

---

# تغییر نوع داده (Type Conversion)

گاهی لازم است یک نوع داده را به نوع دیگری تبدیل کنیم.

مثال:

```python
number = "10"

converted = int(number)
```

اکنون:

```python
converted
```

برابر است با:

```python
10
```

از نوع:

```python
int
```

---

# نام‌گذاری متغیرها

بهتر است نام متغیرها معنی‌دار باشند.

خوب:

```python
domain
record_type
dns_server
```

ضعیف:

```python
x
a
test
```

---

# قوانین نام‌گذاری

نام متغیر:

<p dir='rtl'>
• نباید با عدد شروع شود. <br>
• نباید شامل فاصله باشد. <br>
• نباید از کلمات رزروشده پایتون استفاده کند.
</p>

غلط:

```python
1domain = "google.com"
```

غلط:

```python
record type = "A"
```

درست:

```python
record_type = "A"
```

---

# سبک نام‌گذاری در پروژه

در پروژه DNS Lookup از سبک:

```python
snake_case
```

استفاده کرده‌ایم.

مثال:

```python
record_type
validate_domain
lookup_record
build_dns_results
```

این سبک استاندارد پیشنهادی PEP 8 است.

---

# ارتباط با پروژه DNS Lookup

در پروژه واقعی با متغیرهایی مشابه موارد زیر روبه‌رو خواهیم شد:

```python
domain = "google.com"
record_type = "A"
```

و سپس:

```python
lookup_record(
    domain,
    record_type,
)
```

در اینجا:

<div align='right'>

<span dir='rtl'>• `domain` یک رشته است. </span> <br>
<span dir='rtl'>• `record_type` یک رشته است. </span> <br>
<span dir='rtl'>• نتیجه تابع یک لیست از رشته‌ها خواهد بود. </span>

</div>

---

# تمرین

<div align='right'>

۱. متغیری به نام `domain` ایجاد کنید و مقدار `"example.com"` را در آن ذخیره کنید.

۲. متغیری به نام `record_type` ایجاد کنید و مقدار `"MX"` را در آن قرار دهید.

۳. با استفاده از `type()` نوع هر دو متغیر را نمایش دهید.

۴. متغیری به نام `records_found` بسازید و مقدار `5` را در آن ذخیره کنید.

۵. بررسی کنید که نوع `records_found` چیست.

</div>
