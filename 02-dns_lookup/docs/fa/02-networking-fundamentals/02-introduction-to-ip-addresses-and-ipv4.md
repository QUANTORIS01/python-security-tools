# درس 2: آشنایی با IP Address و IPv4

## مقدمه

در درس قبل یاد گرفتیم که DNS نام دامنه را به IP Address تبدیل می‌کند.

اما هنوز دقیقاً نمی‌دانیم IP چیست و چه ساختاری دارد.

در این درس با مهم‌ترین مفهوم شبکه یعنی:

```text
IP Address
```

آشنا می‌شویم.

---

<div align='right'>

## <span dir='rtl'>IP Address چیست؟</span>

</div>

<p dir='rtl'>
IP Address مخفف:
</p>

```text
Internet Protocol Address
```

است.

هر دستگاهی که در یک شبکه مبتنی بر IP قرار دارد باید یک آدرس منحصربه‌فرد داشته باشد.

مشابه آدرس پستی:

<div align='right'>

```text
خانه ← آدرس پستی
کامپیوتر ← IP Address
```

</div>

بدون IP هیچ دستگاهی نمی‌تواند با دستگاه دیگری ارتباط برقرار کند.

---

## نمونه IP

مثال:

```text
8.8.8.8
```

یا:

```text
142.250.186.14
```

یا:

```text
192.168.1.10
```

این‌ها همگی نمونه‌هایی از آدرس IPv4 هستند.

---

<div align='right'>

## <span dir='rtl'>IPv4 چیست؟</span>

</div>

نسخه چهارم پروتکل IP را:

```text
IPv4
```

می‌نامیم.

امروزه هنوز بخش بزرگی از اینترنت از IPv4 استفاده می‌کند.

---

## ساختار IPv4

یک IPv4 از چهار عدد تشکیل شده است:

```text
192.168.1.10
```

هر قسمت را:

```text
Octet
```

می‌نامند.

پس داریم:

```text
192 | 168 | 1 | 10
```

---

## محدوده هر Octet

هر Octet می‌تواند مقداری بین:

```text
0 تا 255
```

داشته باشد.

مثال معتبر:

```text
192.168.1.1
```

مثال نامعتبر:

```text
300.168.1.1
```

زیرا:

```text
300 > 255
```

---

## چرا فقط تا 255؟

هر Octet برابر است با:

```text
8 بیت
```

بنابراین:

```text
00000000
```

تا:

```text
11111111
```

را پوشش می‌دهد.

بیشترین مقدار ممکن:

```text
255
```

است.

---

## نمایش باینری IPv4

مثال:

```text
192.168.1.10
```

به صورت باینری:

```text
11000000.10101000.00000001.00001010
```

---

## تعداد کل IPv4ها

<p dir='rtl'>
IPv4 دارای:
</p>

```text
32 بیت
```

است.

بنابراین:

```text
2^32
```

آدرس ممکن وجود دارد.

تقریباً:

```text
4.3 میلیارد
```

آدرس.

---

<div align='right'>

## <span dir='rtl'>Network و Host</span>

</div>

یک IP معمولاً دو بخش دارد:

```text
Network Portion
Host Portion
```

مثال:

```text
192.168.1.10
```

در بسیاری از شبکه‌های خانگی:

```text
192.168.1
```

بخش شبکه است.

و:

```text
10
```

شناسه دستگاه محسوب می‌شود.

---

<div align='right'>

## <span dir='rtl'>Public IP چیست؟</span>

</div>

<p dir='rtl'>
Public IP آدرسی است که روی اینترنت قابل مشاهده باشد.
</p>

مثال:

```text
8.8.8.8
```

این IP متعلق به DNS عمومی گوگل است.

هر دستگاهی در اینترنت می‌تواند به آن دسترسی داشته باشد.

---

<div align='right'>

## <span dir='rtl'>Private IP چیست؟</span>

</div>

بعضی IPها فقط داخل شبکه‌های داخلی استفاده می‌شوند.

به آن‌ها می‌گوییم:

```text
Private IP
```

---

## محدوده‌های Private IP

### کلاس A

```text
10.0.0.0
تا
10.255.255.255
```

---

### کلاس B

```text
172.16.0.0
تا
172.31.255.255
```

---

### کلاس C

```text
192.168.0.0
تا
192.168.255.255
```

---

## مثال شبکه خانگی

معمولاً روتر خانه شما IPهایی شبیه این اختصاص می‌دهد:

```text
192.168.1.2
192.168.1.3
192.168.1.4
```

این IPها در اینترنت قابل مشاهده نیستند.

---

## تبدیل Private IP به Public IP

روتر از تکنیکی به نام:

```text
NAT
```

استفاده می‌کند.

فرآیند:

```text
Laptop
192.168.1.10
      ↓
Router (NAT)
      ↓
Public IP
      ↓
Internet
```

---

<div align='right'>

## <span dir='rtl'>IPv4 در پروژه DNS Lookup</span>

</div>

زمانی که این دستور را اجرا می‌کنیم:

```bash
python -m src.cli google.com A
```

معمولاً پاسخ شامل IPv4 خواهد بود:

```text
google.com
↓
216.239.38.120
```

رکورد:

```text
A
```

برای دریافت IPv4 استفاده می‌شود.

---

## تفاوت A و AAAA

رکورد:

```text
A
```

برای IPv4 است.

مثال:

```text
216.239.38.120
```

اما:

```text
AAAA
```

برای IPv6 استفاده می‌شود.

مثال:

```text
2001:4860:4860::8888
```

<p dir='rtl'>
IPv6 را در درس‌های بعدی بررسی می‌کنیم.
</p>
